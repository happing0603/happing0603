# team jcw website

Static site (no build step). Open `index.html`, or publish with GitHub Pages
(Settings > Pages > Deploy from branch > `main` / root).

- `index.html` main · `apply.html` team apply · `shop.html` · `cart.html` · `checkout.html`
- `assets/` images, logos, music · `js/` page scripts (`dc.js` is a tiny template runtime)
- Cart/order data uses the browser's localStorage. There is no real payment; checkout builds an order sheet to send by Instagram DM.
